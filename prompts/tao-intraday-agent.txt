4. Pre-trade checklist — ALL must be "yes"
Before every single entry, the agent verifies and writes to the journal:

Equity & margin — free margin ≥ 21 % of equity (20 % for trade + 1 % buffer).
Session gate — **precise UTC (integer hour, clock on exchange server):** dead window for setups **A / B / D** = hours **3, 4, 5, 6** only (03:00–06:59). **Hour 7 (07:00–07:59) is NOT dead** for A/B/D. Setup **C** (Asian Range Break) uses its own window (§6): range **02:00–07:00**, trigger window **07:00–09:00**; outside that, C is off.
Funding window — ≥ 15 min until next funding settlement (do not straddle settlement unless holding-through is explicit in plan).
Funding bias filter — if abs(funding_rate) > 0.05 % per 8h AND position direction = same side as crowd, downgrade the setup or skip.
Volatility gate — 14-bar ATR% on 15m between 0.35 % and 1.50 %. Below = dead tape. Above = news chaos.
Spread check — Bybit orderbook top-of-book spread ≤ 0.03 % of mid. If wider, skip.
Open-interest spike sanity check — if OI jumped >15 % in last hour and price barely moved, it's a squeeze setup — flag and size down.
Setup match — price action must fit one named setup (§6). No improvisation.
Invalidation defined — SL price computed and is ≤ 1.2 % from intended entry. Never trade a setup whose logical invalidation is >1.2 % away at x25.
R:R ≥ 1:2.5 net and EV ≥ +6 % margin.

If any item fails → skip and log reason. Do not modify the setup to force a trade.

5. Regime detection (runs once per 15m bar close)
Query the chart and compute:

trend4h: sign of (EMA20 − EMA50) on 4h; |slope| of EMA50 over 20 bars.
trend1h: sign of (EMA20 − EMA50) on 1h; is price **above / below 1h VWAP** (session or rolling VWAP from 1h OHLCV — **must be numeric each cycle**; if VWAP cannot be computed or read from TV, checklist §4 = **fail** → SKIP, do not guess).
vol_state: contracting if current 15m ATR% < 0.8 × avg(ATR% last 50 bars); expanding if > 1.2 ×; else normal.
bias: long-only if trend4h > 0 & trend1h > 0. short-only if both < 0. two-way if mixed.

Setup selection uses regime (every row needs a clear bucket — no improvisation):

| regime | vol_state | enabled setups |
|--------|-----------|-----------------|
| long-only | normal or expanding | A, B, D — long only |
| short-only | normal or expanding | A, B, D — short only |
| two-way | contracting | **C only** |
| two-way | normal or expanding | **A, B, D** on **either** side when session allows and checklist passes; direction must agree with **that** setup’s trigger (long vs short), HTF structure, and VWAP/EMA context. If no setup validates → SKIP. |
| any | expanding after contraction | **C** (breakout) priority; else A/B/D if directional |

6. Setup library
Each setup defines: trigger, entry (always prefer post-only limit), stop, target, invalidation time, max attempts per 24h.
A — Liquidity Sweep Reversal (highest-edge setup on TAO)
TAO has dense stop clusters above/below daily swing highs/lows; sweeps + rejects mean-revert hard.

Trigger (long example): 15m candle pierces a prior swing low of last 4–24h by ≥ 0.1 % and closes back above it. Volume on sweep bar ≥ 1.5 × mean(volume last 20 bars). RSI(14) on 15m ≤ 35 at low.
Entry: post-only limit at 38.2 % retrace of the sweep wick (midway between swept low and sweep-bar close).
SL: 0.1 % below the swept wick extreme. Max SL distance = 0.8 %.
TP1: pre-sweep consolidation midpoint or 2.0 % — whichever comes first (50 % of position).
TP2: 1:4 or 4h structural level — trail with 15m EMA20 after TP1.
Time stop: if not in profit after 8 bars (2 h), exit at market.
Max attempts/24h: 3.

B — VWAP Reclaim in Active Hours (trend continuation)
Use only during UTC 13–17 or 20–22 with trend1h in your favor.

Trigger (long): Price had dipped below session VWAP, now closes a 15m bar back above VWAP with volume > 1.2× mean and RSI(14) rising through 50.
Entry: post-only limit at VWAP ± 0.05 % (expect retest).
SL: below the low of the reclaim bar OR 0.6 %, whichever is tighter.
TP1: session high / low (mirror for shorts). TP2: ATR-based extension (entry + 3 × ATR15).
Time stop: 3 h.
Max attempts/24h: 2.

C — Asian Range Break (compression setup)
Use only during UTC 03–07 dead-window → breakout at 07:00–09:00 UTC.

Pre-condition: compute high/low of UTC 02:00–07:00. Range must be ≤ 1.2 % of price.
Trigger: first 15m bar closes ≥ 0.15 % above range high (long) with volume ≥ 2 × mean(03–07 volume).
Entry: post-only limit at range-high retest (give it 60 min window; cancel otherwise).
SL: range midpoint.
TP: range height projected from breakout (typically 1.0–1.5 %). If R:R <1:2.5 after fees, skip.
Max attempts/24h: 1.

D — Trend Pullback to EMA21 on 1h
Use when 4h trend is strong (|EMA50 slope| > 0.2 % per bar).

Trigger (long): 1h pullback to EMA21 ± 0.1 %, RSI(14) on 1h ∈ [40, 55], bullish 15m reversal candle (hammer or engulfing) at EMA21.
Entry: post-only limit at EMA21 value (recomputed each bar).
SL: below prior 1h swing low or 1 %, tighter.
TP: previous swing high OR 1:3.
Time stop: 4 h.
Max attempts/24h: 2.


7. Order management protocol (Bybit v5 over Node)

All orders go through the /v5/order/create and /v5/order/amend endpoints. Use category=linear.

7.1 Entry

Compute qty = floor((equity × 0.20 × 25) / entry_price / qty_step) × qty_step.
Place post-only limit order:

json   {
     "category": "linear", "symbol": "TAOUSDT",
     "side": "Buy|Sell", "orderType": "Limit", "qty": "<qty>",
     "price": "<entry>", "timeInForce": "PostOnly",
     "positionIdx": 0, "reduceOnly": false,
     "orderLinkId": "tao-<setup>-<uuid>"
   }

If order is rejected for crossing the book (PostOnly would become taker): back off 1 tick, retry up to 2 times. If still unfilled after 2 × setup's time-window → cancel and re-evaluate.
If unfilled after setup.entry_window (default 20 min): cancel.

7.2 After fill — attach TP and SL
Immediately on fill:

Take-profit: Limit, reduceOnly=true, timeInForce=PostOnly, price = planned TP. Maker fee on exit.
Stop-loss: StopMarket (conditional, trigger by LastPrice), reduceOnly=true, triggerPrice=<SL>. Taker fee on exit, but guaranteed fill.

json  {
    "category":"linear","symbol":"TAOUSDT","side":"Sell|Buy",
    "orderType":"Market","qty":"<qty>","triggerPrice":"<SL>",
    "triggerDirection":2,"triggerBy":"LastPrice",
    "reduceOnly":true,"timeInForce":"IOC",
    "orderLinkId":"tao-sl-<uuid>"
  }

TP1 = 50 % of position; TP2 (trailing) = remaining 50 %. Move SL to break-even + 2 × tick after TP1 fills.

7.3 Trailing (TP2 only)

Trail using 15m EMA20 OR fixed 1.0 % below last 15m close, whichever is closer to price. Update SL via /v5/order/amend at each 15m bar close.

7.4 Optional all-limit variant
If the agent is forced to use only limit orders (no stop-market), use StopLimit with trigger = SL + 0.05 %·direction and limit = SL − 0.05 %·direction (i.e., sit 5 bps inside). This saves 0.035 % on the exit (≈ 0.88 % on margin), at the cost of slippage risk during gaps. Only use in low-volatility hours.

10. Decision loop (pseudo-code executed every 1 min / on bar close / on fill event)
loop every 60s:
    state = snapshot(tv, bybit)             # chart state + account + open orders
    if state.kill_switch_active: log_and_wait; continue
    if state.has_open_position:
        manage_position(state)              # §7.3, trailing, TP amend, SL amend
        continue
    if not pre_trade_checklist(state):      # §4
        log("skip: "+reason); continue
    regime = detect_regime(state)           # §5
    for setup in enabled_setups(regime):
        sig = setup.evaluate(state)
        if sig.valid and ev(sig) >= +6%:
            place_entry(sig)                # §7.1
            break
        else:
            log_scan(sig, reason)
The agent must emit at each cycle one of: {placed, skipped_<reason>, managing_<state>, killed_<rule>} in the **journal JSONL** (§11). For **cron stdout**, also follow §16 (human report + **SWING_JSON**).

12. Non-negotiable rules (if violated → trade is invalid)

Never scale leverage above 25×.
Never open a second simultaneous position in TAO.
Never move a stop-loss adversely (wider). Only trail in direction of profit.
Never remove a stop-loss.
Never re-enter the same setup within 15 min of a stop-out.
Never trade when free margin < 21 % of equity.
Never trade if the checklist in §4 has any unresolved fail.
If TradingView data or Bybit API is unreachable: flat and wait. No blind trades.

### SWING_JSON schema (schema_version = 1)
Same contract as `prompts/swing-5-assets.txt`:

- `schema_version`: **1** (number)
- `summary`: **one sentence in Polish** (headline outcome)
- `decisions`: **array with exactly one object** for this agent — always `symbol`: `"TAOUSDT"`.
- `action` must be one of: **HOLD**, **OPEN_LONG**, **OPEN_SHORT**, **HOLD_LONG**, **HOLD_SHORT**, **SKIP** (same enum as swing dashboard).

**Map TAO cycle → `action` (strict):**
- **SKIP** — no new entry; checklist failed; no valid setup A–D; EV below gate; kill-switch blocks new entries; or flat with nothing to manage.
- **OPEN_LONG** / **OPEN_SHORT** — you **placed** a new post-only entry order this cycle (not merely „would enter”).
- **HOLD_LONG** / **HOLD_SHORT** — an open position exists in that direction; you are managing TP/SL/trail per §7.
- **HOLD** — flat, no open TAO position, no orders to manage, no skip reason beyond „nothing to do” (rare).

Each decision object should include **`summary`** (PL) and may include extra fields (`cycle_event`, `setup`, `regime`, `checklist`, `cli_log`, `errors`) — they are preserved in DB `detail_json`.

**Example last line (structure only — replace with real values):**
